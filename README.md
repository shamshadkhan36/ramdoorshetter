## 🛠️ Interactive Features

1. **Interactive Shutter Simulator & Remote Handset**
   - Interactive UP, STOP, DOWN motorized remote handset with LED signal.
   - Slat Profile Switcher (Solid Steel, Perforated Mesh, Crystal Polycarbonate).
   - Live Security, Airflow, and Visibility HUD indicators.

2. **Instant Cost Estimator & WhatsApp Generator**
   - Quick size presets (Shop 10x10, Garage 12x10, Warehouse 16x14, Industrial 20x18).
   - Width and height sliders with real-time price range calculation.
   - 1-Click **"Send Estimate on WhatsApp"** button.

3. **Fully Responsive Across All Devices**
   - **Mobile (320px–480px)**: Sticky bottom quick-action bar (`Call`, `WhatsApp`, `Estimate`, `Inquire`).
   - **Tablet (768px–1024px)**: Fluid 2-column balanced grid.
   - **Desktop (1024px+)**: 4-column product categories with 3D parallax tilt & left floating action dock.

4. **Animations & Micro-Interactions**
   - Zero-dependency scroll-reveal animations (`IntersectionObserver`).
   - Animated dynamic number counters (`20+`, `50+`, `10,000+`, `500+`).
   - Hover zoom effects and 3D card tilt.

## 🚀 How to Run Locally

### Option 1: Direct File Opening
Double-click `index.html` in your file explorer to open it in any modern browser.

### Option 2: Run a Local Web Server
```powershell
python -m http.server 8000
```
Then visit [http://localhost:8000](http://localhost:8000).

## 🌐 Deploying to GitHub Pages (Free Hosting)

1. Go to your repository settings on GitHub:  
   `https://github.com/shamshadkhan36/ramdoorshetter/settings/pages`
2. Under **Build and deployment** > **Source**, select **Deploy from a branch**.
3. Choose the `main` branch and folder `/ (root)`, then click **Save**.
4. Your website will be live in 1-2 minutes at:  
   `https://shamshadkhan36.github.io/ramdoorshetter/`
